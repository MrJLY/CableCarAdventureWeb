## 待修复

### P1
- [ ] **暂停时障碍仍在动**。`Game.step()` 的 `paused` 分支依然调用 `obstacles.update()`，而且 `elapsed` 一直在累加，导致暂停时摆锤、闸门相位继续走。应该冻结 `elapsed` 并跳过障碍更新（`src/game.ts` 的 `step`）。
- [ ] **开局无敌闪烁**。`Cabin.resetTo()` 固定给 1.4s 无敌，`resetRun()` 走这条路，重开时会闪；开局没有任何威胁，闪烁纯属干扰。建议 `resetTo(s, invulnerable = true)` 加参数，开局传 `false`。
- [ ] **倒车时相机滞后**。相机 lerp 系数 0.14/帧，快速倒车时车厢会跑出画面左侧。可对负向速度做更快的跟随，或把 lerp 改成按 dt 计算。
- [ ] **同时按住加速和减速**。两边 apply 是叠加的（净效果 = 减速），行为不直观，建议做互斥或明确优先级。

### P2
- [ ] 道具只避开了环轨，没有避开障碍，可能刷在蒸汽喷口或闸门正中间——吃到道具的同时必被击中。需要加一层「与障碍弧长距离 < 400 就挪位」的过滤。
- [ ] `Cabin.speed` getter 未被使用（死代码，`src/entities.ts`）。
- [ ] `RockZone` 的 `x` 只在构造时写入 sprite，若后续要动态换列需同步修改（`src/hazards.ts`）。
- [ ] 浓雾段云团是固定 alpha 叠加，与背景云重合时可能过白，真机需复检。

## 待优化

### 性能
- [ ] **每帧重建矢量的对象**：车厢吊绳、摆锤绳、闸门电弧、蒸汽气柱。吊绳可以改成一根固定长度的 Sprite 缩放；电弧/气柱可以用预烘焙纹理做位移 + 透明度动画。
- [ ] **天空**：48 段色带 `drawRect`，改成一张竖向渐变纹理（`Texture.from(canvas)`，小游戏上要验证）。
- [ ] **地形**：覆盖 9000px 的单个 Graphics，改成按 1000px 分块 + 视锥剔除，减少首帧三角化时间。
- [ ] **金币**：逐个 Sprite（约 60 个），可换粒子批量渲染。
- [ ] **动态分辨率**：低端机把 `resolution` 从 `min(dpr, 2)` 降到 1.5，或按实测帧率自适应。
- [ ] **首帧白屏**：`buildArt` + 地形构建都在主线程同步执行，约 60 张纹理烘焙，可考虑分帧烘焙 + loading 进度。

### 代码结构
- [ ] `src/game.ts` 偏大，职责混杂。可拆：`Level`（关卡数据与布局）、`CollisionSystem`、`Camera`、`FxLayer`。
- [ ] 关卡数据仍在 `src/levels.ts` 里写死，建议外置为 JSON，便于不改代码出关卡。
- [ ] 区域（冰/风/雾）的视觉和逻辑写在同一个 `addZone` 里，可拆成"数据"与"渲染"两层。
- [ ] 轨道 `FEATURES` 与 `baseGroundY` 强耦合，改轨道形状后岩丘/环轨的落点需要重算。建议把可通行性校验脚本固化到 `scripts/`（目前是一次性脚本，用完即删）。

### 手感
- [ ] 加速/减速的加减速度（900 / 1500）与最高速（620）是拍脑袋定的，建议做可调参数面板试手感。
- [ ] 摆锤目前安全窗口 83%，可做一个全局难度系数统一缩放所有障碍的间距与节奏。
